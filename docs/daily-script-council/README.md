# Daily script council papers

These are the working papers behind [the daily script plan](../daily-script-plan.md). Two councils of five worked on the same brief on 2026-11-23, and the plan merges them. Read the plan first; these files are for checking where a claim came from.

- `claude-1-efficiency-lead.md`: decision framework, valuation, phases and measurement (Claude council lead).
- `claude-2-kol-expert.md`: game strategy, banishes, MP, Museum collecting, unused IoTMs.
- `claude-3-mafia-expert.md`: KoLmafia facilities, the MP stall, restartability and the property map for each daily resource.
- `claude-4-garbo-expert.md`: what garbo does, how to run it beside the Museum work, and how to fence it.
- `claude-5-ash-expert.md`: architecture, state, testing and migration from `dailyGrind`.
- `chatgpt-plan.md`: the ChatGPT council's full plan, as it delivered it.

The memos were written before the merge, so some of their figures were corrected in the plan (for example the Sword of S Words gain and the cause of the MP stall). Paths in them are relative to this repo, to KoLUtils, or to the public garbo, Tour Guide and ChIT repos. The resource ledger they cite is Sacha's "Tquilla resource ledger" doc, which is not in the repo.
